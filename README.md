# Proyecto-Instrumentacion-Unity MUSCLE RUN
Este repositorio contiene el entorno virtual diseñado en Unity por el grupo 3 para el proyecto de la asignatura de Fundamentos de Sistemas e Instrumentación en
el Grado de Ingeniería Biomédica de la Universidad de Alicante.

## Instrucciones de Ejecución
1. Configurar el streaming de datos en el software de Noraxon (IP `192.168.1.120:9220`).
2. Ejecutar el script `muscle_run_proyecto.m` en MATLAB (el sistema se pondrá en modo espera).
3. Abrir este proyecto en Unity y pulsar Play.
4. Pulsar el botón START en la interfaz de Unity para arrancar la fase de calibración automática MVC de 5 segundos por músculo.
